# gyeongbuk-arch-law-mcp

경상북도 건축 실무를 돕는 도구 모음입니다.

1. **건축 법령 조회 MCP 서버** — 국가법령정보센터 오픈API에서 받은 법령을 저장해 조회합니다.
2. **건축물 수전설비 용량 조회(전국)** — 한국전기안전공사가 공개하는 검사·점검 기록에서 시설의
   수전전압(V)·수전용량(kW)을 찾습니다. ① MCP 도구, ② 홈페이지 검색화면, ③ 홈페이지 AI 도우미로 쓸 수 있습니다.

---

## 설치

Node.js 22 이상을 권장합니다(개발·시험 환경: Node.js 22.23.4).

```bash
npm install
cp .env.example .env   # 발급받은 인증키를 .env 에 채우기
npm run build
```

`.env` 는 저장소에 올라가지 않습니다(`.gitignore`). 인증키를 다른 곳에 붙여 넣지 마십시오.

## 건축물 수전설비 용량 조회

### 자료와 법적 근거

| 구분 | 내용 |
|---|---|
| 자료 | 한국전기안전공사 「전기안전정보공개 OpenAPI」 중 **검사점검이력정보**(`inspctResultInfo`) — 공공데이터포털 등록명 「한국전기안전공사_전기안전정보공개 API」(15146770, 제공형태 LINK) |
| 명세 원문 | 전기안전종합정보시스템 「Open API 소개」 <https://www.kes.go.kr/web/lay1/bbs/S1T268C269/E/85/list.do> (2026-11-05 확인) |
| 법적 근거 | 「전기안전관리법」 제21조제1항(정보의 공개), 같은 법 시행령 제10조제2호(공개 대상: 수전설비 및 발전설비의 전압 및 용량) |
| 검사 근거 | 「전기안전관리법」 제9조(사용전검사), 제11조제1항(정기검사) |
| 조회 기간 근거 | 「전기안전관리법 시행규칙」 제8조제1항 및 별표 4 제2호 나목 — 고압 이상 전기수용설비의 정기검사는 2년마다 또는 3년마다(각 전후 2개월), 일부 4년 이내 → 기본 38개월 |

**조회 방식**: 원문 명세상 이 API는 `조회연월(searchYM) + 시도코드(sido) + 구군코드(gugun)` 로만 조회됩니다
(상호·주소 검색 기능 없음). 그래서 지정한 시군의 최근 N개월 자료를 한 달씩 받아 상호·주소 검색어로 걸러 냅니다.
받은 자료는 `data/kesco/cache/` 에 저장해 다음 조회부터 바로 씁니다(이번 달·지난달은 12시간마다 새로 받음).

**단위**: OpenAPI 명세에는 수전전압·수전용량의 단위가 적혀 있지 않습니다. 전기안전종합정보시스템
「검사·점검이력정보」 조회화면이 같은 항목을 '수전 전압(V)', '수전 용량(kW)'으로 표기하고 있어 이에 따라 표시합니다.

**개인정보**: 대표자명·검사점검자명·시공업체 대표자명과 시공업체명은 수전용량 확인 목적과 무관하므로 화면·도구·AI 답변에서 모두 뺍니다.

**자료의 한계**
- 정보 공개는 재량 규정('공개할 수 있다')이므로 모든 시설이 수록되었다고 볼 수 없습니다.
- 조회 기간 안에 검사·점검 기록이 없는 시설은 나타나지 않습니다.
- 결과는 참고용이며, 공식 확인은 한국전기안전공사 또는
  [전기안전종합정보시스템 「검사·점검이력정보」](https://www.kes.go.kr/web/lay1/program/S1T113C118/PI/result/inspctResultInfo.do)에서 하십시오.
- 「한국전기안전공사_안전등급 이력정보」 CSV(공공데이터포털 15145904)는 상호가 가려져 있고 소재지가 시군구까지만 있어
  특정 건물과 대조할 수 없으므로 사용하지 않습니다(전국 176건, 경북 18건, 2026-11-05 확인).

**실측 확인 결과** (2026-11-07, 발급 인증키로 2026년 10월분 구미시·포항시 조회)
- 응답 구조: `{"result": [ … ]}` — 한 달 구미시 243건(약 148KB), 포항시 233건.
- 상호명: 가리지 않은 원문으로 제공됨(가린 기록 0건).
- 주소: 번지가 있는 지번주소 구미 136/243건·포항 169/233건, 건물번호가 있는 도로명주소 구미 168/225건·포항 204/227건. 일부 기록은 번지가 없으므로 상호명이나 동·도로명으로 찾는 것이 확실합니다.
- 포항시: 구군코드 `11` 은 남구·북구 기록을 함께 돌려주고(남구 130·북구 101건), `111`·`113` 은 0건 → '포항시 남구'처럼 입력하면 포항시 전체를 받은 뒤 주소로 거릅니다.
- 명세와 다른 점: 설비타입·검사점검종류·안전등급·검사점검시작일 항목은 응답에 없었고, 안전관리업체·시공업체 대표자 성명 항목이 추가로 있었습니다(표시하지 않음).
- 수전전압 값은 22900·154000·380·220 등, 수전용량은 0~860,007 범위였습니다. 0은 원문 값 그대로 표시합니다.

**⚠️ 남은 확인 사항**
- 한 달 자료가 한 번에 모두 오는지: 응답에 `PAGE_INDEX`·`PAGE_SIZE` 등 페이지 항목이 있으나 값은 아직 확인하지 못했습니다(`npm run kesco:verify` 요약의 `paging` 항목으로 확인 가능).

### 조회 지역 (전국)

- 지역 목록은 **국토교통부 법정동코드**(공공데이터포털 15123287, `국토교통부_법정동코드_20260929`)의 '존재' 코드로 만들었습니다: 시도 16, 시군구 269(시 아래 구 40 포함). `src/elec/regionData.ts` 는 자동 생성 파일이며, 새 자료로 갱신하려면 CSV를 받아 `node dist/scripts/buildRegionData.js <CSV경로> <자료명>` 을 실행합니다.
- 이름으로도 찾습니다(예: `경북 구미시`, `경기 수원시 장안구`, `수원장안구`). `중구`처럼 여러 시도에 있는 이름은 후보를 보여 주고 추측하지 않습니다.
- 지역별 조회 방식 (2026-11-07 `kesco:verify --regions` 실측, 2026년 10월분):

| 지역 | 조회 방식 | 실측 근거 |
|---|---|---|
| 일반 시군구(경북 등) | 현행 법정동코드 앞 2자리=sido, 3~4번째=gugun | 구미 243건, 서울 광진구(11215→21) 101건 |
| 강원 | 현행 코드 51 | 51: 111건, 옛 42: 0건 |
| 전북 | 현행 52 + 옛 45 함께 조회해 합침 | 52: 225건, 45: 1건 |
| 전남광주통합특별시 | 새 코드(12) + 옛 코드(광주 29·전남 46) 함께 조회해 합침 | 광주 동구 12-21: 23건·29-11: 24건, 고흥 12-74: 35건·46-77: 16건 |
| 인천 신설 구(제물포·영종·서해·검단) | 새 코드 + 옛 구(중구·동구·서구) 코드 함께 조회 → 이웃 구역 기록이 섞일 수 있음 | 제물포구 55건·옛 중구 42건, 서해구 137건·옛 서구 169건 |
| 포항시 남구·북구 | 포항시 전체 조회 후 주소로 구를 거름 | 남구 130·북구 101건(주소에 구 이름 있음) |
| 그 밖의 구가 있는 시(수원·성남·안양·부천·안산·고양·용인·화성·청주·천안·창원·전주) | 구를 골라도 시 전체를 보여 줌 | 수원 394·화성 677·창원 459·청주 466건 조회되나 주소에 구 이름 0건 |

여러 코드를 함께 조회할 때 완전히 같은 기록은 한 번만 표시합니다.

### 인증키 신청

1. 전기안전종합정보시스템(<https://www.kes.go.kr>) → OpenAPI → **OpenAPI신청**에서 '검사점검이력정보'를 신청합니다.
2. 관리자 승인 후 인증키가 발급됩니다(활용기간 12개월).
3. `.env` 의 `KESCO_API_KEY=` 뒤에 넣습니다. 인증키는 요청 주소의 `codeNo` 변수로 전달됩니다.

### 인증키 발급 후 실제 응답 검증

인증키를 `.env` 에 넣은 뒤 아래 명령을 실행합니다(사내 프록시 환경은 `npm run kesco:verify:proxy`).

```bash
npm run build
```

```bash
npm run kesco:verify
```

- 실제 API를 최대 7회 호출합니다: 구미시의 지난달 자료(없으면 그 전 달, 최대 3개월)와,
  같은 달 포항시를 구군코드 3가지(`11`, `111`, `113`)로 각 1회.
- 화면에 나오는 '검증 요약'에는 인증키·상호명·주소·성명 원문이 없고, 글자 모양(예: `○○***`)과 건수만 있습니다.
  이 요약을 복사해 전달하면 확인 필요 사항 4건을 판정할 수 있습니다.
- 원본 응답은 `data/kesco/verify/` 에만 저장됩니다(저장소에 올라가지 않음). 개인정보가 있을 수 있으니 공유하지 마십시오.
- 특정 달을 보려면 `npm run kesco:verify -- --month 202510` 처럼 조회연월을 지정합니다.

### 홈페이지 실행 (이 PC에서만 접속)

```bash
npm run build
npm run web
```

브라우저에서 <http://127.0.0.1:3000> 을 엽니다. 서버는 127.0.0.1 에만 열리므로 다른 PC에서는 접속할 수 없습니다.
포트는 `.env` 의 `PORT` 로 바꿀 수 있습니다.

- **검색화면**: 시도(기본 경상북도) → 시군구 → (선택) 상호·주소 검색어 → 조회 기간(기본 38개월) → 구분(기본 자가용) → 조회.
  처음 조회하는 시군은 한 달에 한 번씩 받아 시간이 걸리며 진행률이 표시됩니다. '중지'를 눌러도 이미 받은 달은 저장됩니다.
  결과는 최대 500건까지 표시되며, **'엑셀(CSV)로 내려받기'** 버튼으로 화면의 결과를 파일(`sujeon_시군구코드_날짜.csv`)로 저장할 수 있습니다. 파일 첫 줄에 출처·조건·단위가 적힙니다.
- **AI 도우미**: "구미시 공단동 OO전자 수전용량 알려줘"처럼 질문합니다. 위 검색과 같은 조회 결과만 근거로 답하며,
  결과가 없으면 "확인되지 않습니다"라고 답합니다. 한 번에 받는 결과는 기본 20건, 많은 목록을 요청하면 최대 500건입니다(건수가 많을수록 요금 증가). `.env` 의 `ANTHROPIC_API_KEY` 가 필요하며 질문마다 요금이 발생합니다.
  - 모델: 기본 `claude-opus-5-5` (`ANTHROPIC_MODEL` 로 변경), 사고 깊이 기본 `medium` (`ANTHROPIC_EFFORT`)
  - 공시 단가(100만 토큰당, 2026-10 기준): Opus 5.5 입력 $4 / 출력 $20, Sonnet 5.5 $2 / $10, Haiku 5.5 $0.10 / $0.50
  - 각 답변 아래에 사용 토큰 수가 표시되므로 실제 비용을 확인할 수 있습니다.
  - 모델의 안전 정책상 거절이 나오면 지원 모델에서는 서버 측 예비 모델 전환(`fallbacks: "default"`)이 자동으로 시도됩니다.

### 사내 프록시를 쓰는 경우

Node.js 의 기본 `fetch` 는 `HTTPS_PROXY` 환경변수를 자동으로 따르지 않습니다. 프록시 환경이면 다음 명령으로 실행하십시오
(Node.js 22.23.4 에서 동작 확인, 더 낮은 버전은 지원하지 않을 수 있음).

```bash
npm run web:proxy
```

### MCP 도구 (Claude Desktop 등)

| 도구 | 기능 |
|---|---|
| `elec_list_regions` | 시도 목록, 또는 시도별 시군구와 5자리 시군구코드 |
| `elec_search_capacity` | 시군·검색어·기간·구분으로 수전전압·수전용량과 검사 기록 조회 (진행률 알림 지원) |
| `elec_data_sources` | 출처·법적 근거·단위 근거·자료의 한계·확인 필요 사항·인증키 신청 방법 |

`claude_desktop_config.json` 예 (프록시 환경이면 `args` 맨 앞에 `"--use-env-proxy"` 추가):

```json
{
  "mcpServers": {
    "gyeongbuk-arch-law": {
      "command": "node",
      "args": ["/absolute/path/to/gyeongbuk-arch-law-mcp/dist/index.js"]
    }
  }
}
```

MCP 서버도 저장소 최상위의 `.env` 를 읽습니다.

### 자료 미리 받아두기

조회가 몰리기 전에(예: 퇴근 후) 자료를 미리 받아 저장해 둘 수 있습니다.

```bash
npm run kesco:prefetch -- --sigungu 구미시 --sigungu 포항시
```

```bash
npm run kesco:prefetch -- --all-gyeongbuk
```

다른 시도는 `npm run kesco:prefetch -- --sido 경기` 처럼 받습니다. 전국 일괄 수집(약 250개 시군구 × 38개월 ≈ 9,500회 호출)은 권장하지 않습니다.

경상북도 전체는 22개 시군 × 38개월로 최대 836회 호출하므로 오래 걸립니다. 중간에 멈춰도 다시 실행하면 받은 달은 건너뜁니다.

## 건축 법령 조회 MCP 서버

### ⚠️ 스키마 검증 상태

`src/lawApiTypes.ts` / `src/parseLawApi.ts` / `src/lawApiClient.ts`는 국가법령정보센터
오픈API 응답 구조에 대해 일반적으로 알려진 형태를 "가정"해 작성한 초안입니다.
이 개발 환경은 `law.go.kr` 도메인 접속이 네트워크 프록시에서 차단되어 있어 실제
응답으로 검증하지 못했습니다. 처음 실제 데이터를 받아올 때는 `fetchLaw.js` 실행 로그의
경고 메시지를 꼭 확인하고, 필요하면 `src/lawApiTypes.ts`를 실제 응답에 맞게 수정하세요.

### 법령 데이터 받아오기


### MCP 서버 실행

```bash
npm run build
npm start
```

### 제공 도구

- `law_list_laws` — `data/laws/`에 저장된 법령 목록 조회
- `law_get_law` — lawId로 법령 기본 정보 + 전체 조문 조회
- `law_get_article` — lawId + 조문 번호로 특정 조문 조회
- `law_search_articles` — 저장된 법령들의 조문 텍스트에서 키워드 검색 (페이지네이션 지원)

모든 도구는 `response_format`(`markdown` | `json`)을 지원하며, 아직 데이터를 받아오지
않았다면 `law_list_laws`가 안내 메시지와 함께 빈 목록을 반환합니다.
